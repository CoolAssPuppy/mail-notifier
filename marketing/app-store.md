# Mail Notifier App Store copy

macOS 4.0.0. This snapshot combines the [launch kit](https://ampcode.com/artifacts/mail-notifier-launch-kit-6e6f53b9-2588-479e-ac4d-39551c0d7a0a) and its source copy table with the exact repeat-tip replacements from the [migration thread](https://ampcode.com/threads/T-01a21d66-7797-7632-b540-4e6926d25c4f) (messages 1232 and 1237–1239). That write verified exact App Store Connect readback for all 24 listing descriptions and all 24 Tip Jar descriptions. The version rename preserved all 24 listing records. This is a reconstruction from that verified write, not a fresh localization export.

## Shared fields

- App name in every locale: **Mail Notifier App**.
- Categories: **Productivity** (primary), **Utilities** (secondary).
- Support URL: <https://www.strategicnerds.com/apps/mailnotifier/support>.
- Privacy policy URL: <https://www.strategicnerds.com/apps/mailnotifier/privacy>.
- Marketing URL: <https://www.strategicnerds.com/apps>. The product-specific page described the independent edition when the copy was saved.
- Price: free in all 175 configured storefronts. The app supports unlimited supported accounts. Listing localization does not imply the app UI is translated.
- Tip Jar reference name: **Tip Jar**. Product ID: `com.strategicnerds.MailNotifierApp.tip`. Apple ID: `6840158603`. Type: **Consumable**. Optional and repeatable; never renews or unlocks features. U.S. price: **US$4.99**; StoreKit supplies Apple-generated local prices in the other configured storefronts.

## Review reference (not public listing copy)

- Demo Mode: **Settings → Updates → right-click Current version → Turn Demo Mode on**. It supplies scripted inboxes without signing in or connecting to live mail.
- Tip Jar: **Settings → Support Mail Notifier → Send a tip**. Tipping or canceling does not change mail access. Use the separate [review-only screenshot](review-only/tip-jar.png). Check the review note before submitting: the earlier saved note still referred to a one-time tip, and the localization correction did not update it. No reviewer contacts or credentials are included.
- The saved public copy names Microsoft 365. The launch kit records an authorization probe, not a successful work or school mailbox check. Confirm supported account types and any tenant approval limits before publication.
